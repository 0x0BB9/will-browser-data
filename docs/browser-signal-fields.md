# Browser Risk Signals 字段说明

本文档用于说明当前前端页面中已经保留并展示的浏览器环境字段，便于其他团队了解我们当前拿了哪些数据、这些数据分别属于哪个模块、字段含义是什么。

当前页面中的这批环境字段来自 `browser-tool` 的 `getInfo()` 结果，并经过一轮字段筛选：
- 已保留：相对稳定、适合进入字段池的主字段
- 已隐藏：灰度观察字段，暂时不在页面中展示
- 已剔除：可信度较低或默认值风险较高的字段

## 1. 浏览器与系统

这一组字段主要用于识别浏览器类型、系统环境、WebView 场景，以及做 UA 一致性校验。

| 字段名 | 中文含义 | 示例 | 说明 |
| --- | --- | --- | --- |
| `browser` | 浏览器 | `Firefox` | 浏览器名称 |
| `browserVersion` | 浏览器版本 | `137` | 浏览器主版本或版本号 |
| `engine` | 渲染引擎 | `Gecko` | 浏览器底层渲染引擎 |
| `system` | 操作系统 | `macOS` | 操作系统名称 |
| `systemVersion` | 操作系统版本 | `10` | 由 UA 或平台信息解析出的系统版本 |
| `platform` | 硬件平台 | `MacIntel` | 浏览器暴露的平台字符串 |
| `architecture` | CPU 架构 | `x86` | 设备 CPU 架构信息 |
| `userAgent` | 用户代理 | `Mozilla/5.0 ...` | 原始 UA 字符串 |
| `cookieEnabled` | 是否启用 Cookie | `true` | 浏览器是否允许 Cookie |
| `isWebview` | 是否为 WebView 容器 | `false` | 识别是否处于 App 内嵌浏览器/容器环境 |
| `isRobot` | 是否为机器人/爬虫 | `false` | 基于 UA 等规则做的机器人识别结果 |

## 2. 设备与屏幕

这一组字段主要用于描述设备类型、屏幕能力、视口尺寸，适合做设备画像和终端环境分析。

| 字段名 | 中文含义 | 示例 | 说明 |
| --- | --- | --- | --- |
| `device` | 设备类型 | `Desktop` | 终端类型，如桌面端、移动端、平板 |
| `devicePixelRatio` | 设备像素比 | `2` | CSS 像素与物理像素的比值 |
| `screenWidth` | 屏幕宽度 | `1920` | 设备屏幕宽度，单位像素 |
| `screenHeight` | 屏幕高度 | `1080` | 设备屏幕高度，单位像素 |
| `clientWidth` | 可视区域宽度 | `1415` | 浏览器当前可视区域宽度 |
| `clientHeight` | 可视区域高度 | `943` | 浏览器当前可视区域高度 |
| `screenColorDepth` | 屏幕色彩深度 | `30` | 屏幕颜色深度 |
| `screenPixelDepth` | 屏幕像素深度 | `30` | 屏幕像素深度 |
| `isTouch` | 是否支持触屏 | `false` | 浏览器/设备是否支持触控能力 |

## 3. 网络与区域

这一组字段主要用于描述浏览器在线状态、语言和时区，适合做区域偏好和环境一致性分析。

| 字段名 | 中文含义 | 示例 | 说明 |
| --- | --- | --- | --- |
| `isOnline` | 在线状态 | `true` | 浏览器在线标记，表示浏览器认为当前设备具备联网能力，不等于业务服务一定可达 |
| `language` | 系统语言 | `zh_CN` | 浏览器当前语言设置 |
| `timezone` | 时区 | `Asia/Shanghai` | 浏览器当前时区 |

## 当前未展示字段

以下字段当前没有在页面中展示，但其中一部分仍可能在底层采集中保留，后续可根据需要重新评估。

### 灰度观察，暂时隐藏

| 字段名 | 中文含义 | 原因 |
| --- | --- | --- |
| `gpu` | GPU 厂商信息 | 空值率和浏览器差异较高，暂时不作为主字段展示 |
| `gpuModel` | GPU 型号 | 对隐私限制较敏感，稳定性一般 |
| `screenFPS` | 屏幕刷新率 | 易受浏览器采样和运行状态影响 |
| `network` | 网络类型 | 经常为 `unknown`，解释性和稳定性一般 |

### 低可信，已剔除

| 字段名 | 中文含义 | 原因 |
| --- | --- | --- |
| `ip` | WebRTC 推断 IP | 不是稳定公网 IP，波动和误差较大 |
| `battery` | 电池电量 | 很多环境拿不到真实值，容易回退默认值 |
| `isCharging` | 是否在充电 | 与 `battery` 类似，真实性不足 |
| `deviceMemory` | 设备内存 | 常见默认值回退，区分度有限 |
| `bitness` | 系统位数 | 推断准确性不稳定，存在误判风险 |
